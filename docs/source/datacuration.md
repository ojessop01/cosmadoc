# Data curation

COSMA can help you move, share, publish and keep the data your projects
produce.  This page lists the options; for most of them, contact
cosma-support to set things up.

## Moving data

To copy data between COSMA and other systems, see
[data transfer](data.md), which covers `rsync`, `scp` and other tools, and
[Lustre](lustre.md#copying-data-onto-lustre) for copying large files onto
COSMA's file systems.

## Sharing data with other researchers

| Option | Suits |
| ------ | ----- |
| [Access control lists](acl.md) | Giving other COSMA users access to your files, without copying them |
| Web download | Making files available to anyone with a link |
| S3 exports | Letting others read or mount the data with S3-compatible tools |
| [StorJ](storj.md) | Sharing through the StorJ decentralised storage network |

For web downloads and S3 exports, contact cosma-support, saying how much data
you want to share and who needs access to it.  Data already shared from COSMA
is listed on the [data links](links.md) page.

## Databases and web front ends

If your data would be more useful through a database or a web interface,
such as the existing EAGLE and Millennium databases, contact cosma-support to
discuss it.

## Long-term storage and archiving

Data you no longer need on disk can be archived to tape (see
[archive](archive.md)).  COSMA can also offer longer-term storage for some
data, with some conditions.  Contact cosma-support to discuss what you need,
including how much data there is and how long it must be kept.
