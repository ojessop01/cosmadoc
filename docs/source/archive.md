# Archiving to tape

COSMA has a tape archive for data that you want to keep but no longer need on
disk, such as the outputs of finished simulations.  Archived data can be
restored to disk when you need it again.  The archive uses the Atempo Miria
software.

## Archiving data

COSMA staff can archive directories for you.  Contact cosma-support with:

- the directories to archive, and how much data they hold;
- whether the originals should be deleted from disk once the archive has been
  checked;
- how long the data needs to be kept.

You can also manage archiving yourself.  Ask cosma-support to set this up.  If
you manage your own transfers, you are responsible for checking that they
completed correctly before deleting anything from disk.

Archiving works best with a smaller number of large files.  If a directory
holds very many small files, combine them first, for example into `tar` files.

## Restoring data

To restore archived data to disk, contact cosma-support, saying which data you
need and where it should go.  Restoring from tape takes time, so ask well
before you need the data.

## How long data is kept

Tape storage is long-term, but not permanent: tape hardware is replaced over
the years, and data must be moved to new systems.  Check from time to time
that your archived data is still there, and move it to the newest tape system
when new hardware is bought.
