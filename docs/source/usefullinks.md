# Useful links

Other resources for learning about HPC.  These are external sites, so they may
change.

- [Awesome High Performance Computing](https://github.com/trevor-vincent/awesome-high-performance-computing):
  a large, curated list of HPC resources, tools and courses.
- [UK HPC facilities](https://www.ccpahc.ac.uk/resources/sites/): a list of HPC
  services in the UK.
- [Foundations of High-Performance Computing](https://360.articulate.com/review/content/df08a035-b9d6-4de4-ae5f-4c62b33bc67b/review):
  an online introductory course.
- [DiRAC training](https://dirac.ac.uk/training/): training courses and the
  [DiRAC Essentials Test](essentials.md).
- [HPC Carpentry](https://www.hpc-carpentry.org/): lessons on using HPC
  systems, the command line and job schedulers.
- [Software Carpentry](https://software-carpentry.org/lessons/): lessons on
  the Unix shell, git and programming in Python.
